# 月度生产表生成器设计说明

## 目标

把现有月度生产表转换逻辑封装为一个无需 Codex 的桌面程序，同时支持 macOS 和 Windows。

## 用户流程

1. 选择一个符合模板结构的 `.xlsx` 文件。
2. 修改自动读取的表格标题。
3. 输入起始日期和结束日期。
4. 按需添加多条行高和列宽规则。
5. 选择输出文件位置并生成新工作簿。
6. 通过“帮助”按钮打开随应用提供的离线电子帮助。

## 工作簿规则

- 日期使用真实公历，起止日期均包含在内，正确处理大小月、二月和闰年。
- 第一张工作表使用原模板中 25 日页的期初公式；之后各页引用前一页生成累计公式。
- 日期写入每张工作表的 `G4`，标题写入 `A1`，保留这些单元格的既有样式。
- 清空已知手工录入单元格与填写人，保留固定文字、样式、打印设置和公式区域。
- 日号不重复时页签使用日号；重复时使用 `MM-DD`；仍重复时使用完整日期。
- 第一张的年累计为当日日累加源工作簿年累基数；生成范围内实际遇到 1 月 1 日时从当日数据重新累计。
- 输出文件名包含完整起止日期。

## 行列尺寸

- 一条规则包含范围、数值和单位。
- 行范围支持 `4`、`4,8,12`、`4-12`、`4-8,12,15-18`。
- 列范围支持 `A`、`A,C,F`、`A:F`、`A:C,F,H:J`。
- 单位支持字符、厘米、毫米、英寸。
- 多条规则按列表顺序应用；重复指定时最后一条生效。
- 未指定的行列保留模板尺寸；规则应用于所有生成的日期工作表。

## 桌面界面

使用 Python Tkinter 实现单窗口。窗口包含模板、标题、起止日期、输出位置、行高规则、列宽规则、生成按钮和帮助按钮。输入错误及模板不匹配均显示中文提示。

## 发布方式

- macOS：PyInstaller `.app`。
- Windows：PyInstaller 单文件 `.exe`。
- 两个平台共用同一代码和离线 `help.html`。
- Windows 产物必须在 Windows 环境构建；项目提供本机构建脚本和 GitHub Actions 双平台构建配置。

## 多模板与供应商

- 自动识别生产入库发运表、化肥矿石用量表、产消存计划表和调度生产信息表。
- 三种旧版 `.xls` 模板转换后输出 `.xlsx`；日期、页签及公式页签引用同步更新，计算逻辑保持不变。
- 化肥矿石用量表和调度生产信息表支持供应商改名及在汇总行前新增供应商。
- 产消存计划表支持在“生产日累”或“当日配送量”区域新增供应商，也支持区域内改名。
